    入门¶

    在我们正式开始之前，我们需要先问自己几个一个问题。

    我是否具备基本的计算机理论知识？¶

    此处的“知识”主要是指诸如分区，引导以及操作系统相关知识等等基本的操作系统运维概念，不需要深入了解。

    如果你在实践的过程中发现了不太了解的名词，可以看一看我们编写的“概念”部分来补课。

    警告

    我们不推荐小白跳过理解直接安装，否则可能导致您所使用设备的操作系统产生不稳定性或发生严重损坏！！！造成的损失不由LinuxCabin组织以及文档贡献者承担！！！

    我为什么要使用Linux？¶

    尽管看起来可能有点啰唆，但这是一个非常重要的问题，它从会根本上决定我们后续的所有选择。

    1. Windows太烂了，想要叛逃Linux¶

    是的，Microslop越来越多的垃圾广告、卡顿和充满bug的系统、爆满的C盘等等等等的问题，的确令用户难以忍受。所以，我们选择了Linux，它简洁，轻量，没有烦人的商业化行为，的的确确是很好的选择。

    不过，下面有一些需要您在这之前检查的事情：

    1. 我日常所需的软件是否有Linux版本/替代品/兼容选项？
      您可以查阅如下数据库:

      • Wine官网数据库（英文）
      • Can We Tux?
      • Are We Anti-Cheat Yet?（英文）
      • Can I Play on Linux?（英文）
      • ProtonDB（英文）

    2. 我能否忍受可能会带来的不便与学习成本？
      这包括可能会和终端打一部分交道，以及可能存在的不稳定性风险。

    3. 我能否完全脱离Windows？
      如果不能，您需要参考“虚拟机”、Wine等章节。

    检查完毕！打开下一章，开始我们的旅途吧！

    2. 我只是单纯好奇，想要尝试/把玩下¶

    你好，开拓者！Linux的广大社区也是像你这样千千万万的具有开拓精神的爱好者用爱发电而形成的，希望你旅途愉快！

    不过请注意，我们的教程主要偏向的是“用”这一部分，如果是想要诸如极客那样的体验，还请移步别处啦 ;-D。

    相信有这样的精神，你一定能够克服接下来的重重阻碍，打开下一章，let's go 🚀！

    3. 我向往自由（软件）¶

    欢迎来到自由世界！Linux自创立之初就是自由软件（准确来说是创立之后不久），并且极大地推动了世界自由软件的发展，是兼顾“支持”与“自由”的选择。

    什么是自由软件？

    从概念上说，“自由软件”指的是赋予用户自由的软件。自由软件通过开放源代码，允许对软件及其源代码进行随意的研究、修改、二次分发等行为保证了用户的自由。
    有两种“自由软件”的理念，一种是 GNU 自由软件理念，另外一种是 BSD 开源软件理念。

    理念¶

    以下分别出示GNU自由软件理念和BSD开源软件理念。

    （GNU）

    0：无论用户出于何种目的，必须可以按照用户意愿，自由地运行该软件。

    1：用户可以自由地学习并修改该软件，必须可以访问到该软件的源代码。

    2：用户可以自由地分发该软件的拷贝，这样就可以助人。

    3：用户可以自由地分发该软件修改后的拷贝，将改进后的软件分享给整个社区令他人也从中受益。

    （BSD）

    0：无论用户出于何种目的，必须可以按照用户意愿，完全自由地运行该软件，且没有任何使用场景的限制。

    1：用户可以自由地学习并修改该软件，必须可以公开访问到该软件的源代码，且原作者不对修改行为作任何审计或干涉。

    2：用户可以自由地分发该软件的原始拷贝或修改后的拷贝，用户可以自由选择以何种许可证分发，只需保留原作者的版权声明即可。

    3：用户可以自由地分发该软件修改后的版本，且不承担任何向社区回馈代码的义务。

    GNU 和 BSD 的不同¶

    GNU 和 BSD 对自由的定义不同：

    • GNU 将自由视为“所有软件用户的自由”，它让基于这份源代码的所有软件都是自由的。
    • BSD 将自由视为“拿到这份源代码的人的自由”，拿到源代码的人可以做任何他们想做的事。

    因此：

    • GNU 式许可较为严格。您可以自由使用、修改和分发软件，但使用您源代码的软件通常必须保持 GNU 式许可，并保持源代码的开放。
    • BSD 式许可较为宽松。您可以自由使用、修改、重新分发，甚至将代码整合到闭源软件中，使用您源代码的软件不必保持自由（或开源）。

    举两个简单的例子：

    • 您修改了 GPL (GNU) 许可的软件，并用在自己的软件里。当您在分发或出售您的新软件时，您必须包括一份源代码。
    • 您修改了 BSD 许可的软件，并用在自己的软件里。您可以随意分发或出售您的新软件，开源或不开源，BSD 不在乎。

    4. 我喜欢Linux酷炫的视觉效果¶

    我们很理解，作为一名小白，在看到网上那些炫酷的桌面的时候，你内心是怎样的震撼。什么具有科技感的状态栏，炫酷的图标，都比Windows要炫酷不少。

    不过，如果单纯是因为视觉效果而入坑，您一定要做好以下的心理准备：

    1. 可能与终端打一点小交道
    2. 你的配置效果很有可能不尽人意
    3. 我们的教程并不全面，只是为入坑而写，如果需要更深入的知识推荐去Arch Wiki | Arch Wiki 中文版深造

    在继续之前，我们建议您首先阅读桌面章节。

    好啦，既然你已经准备好了，那我们就向下继续吧！

    5. 我就是想装逼¶

    如果是这样，我们并不会推荐您使用Linux。众所周知，目前Linux社区“恃才傲物”的问题有很大一部分都是“嘉豪”一类人所造成的。所以，如果您只是单纯想要炫耀自己的技术力，我们不推荐通过Linux而达成这个目的，并且秩序与风气良好的社区是极力反对这种现象的。

    当然，如果您依然想要继续，那么则希望您能与其他用户平等交流，少一些炫耀，多一些真才实干，为社区创造一个相对好的氛围。
